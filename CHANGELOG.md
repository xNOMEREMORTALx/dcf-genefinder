# Changelog
- **v2.32 released (L3229).** The v2.32b candidate passed its blind test on all 6 blind_18 genomes: mean exact-start gain +2.3, no genome lost starts, found/correct changes all < 0.5 (max +0.48). Released logic is identical to the tested candidate (byte-identical output checked on *Nautilia*); research hooks (env vars, dump) dropped. SHA-256 fa30258b...297c.
- **v2.32 candidate blind test (L3213):** exact starts +2.2 points on 13 blind chromosomes (T1 pass), no genome lost starts (T2 pass), but genes found fell by 0.5-0.6 points in 2 of 13 (T3 fail, limit 0.5). **Not released;** v2.31 stays the default until the found loss is understood (lead G-starts c).
- **dcf_secflag.py coding filter (L3197, Sec-3):** optional `--coding T` scores each candidate's read-through part by mean codon log-odds (in-frame vs out-of-frame codon use of the genome's own predicted genes) and keeps scores >= T. Development on blind_14/15 (10 genomes, 28 sites caught): AUC 0.87 (the SECIS hairpin filter reached 0.60-0.69); T = 0.05 kept 28/28 sites and cut candidates by about 55-75% in AT-rich genomes. Default output unchanged. Blind test pre-registered in L3197 (blind_16 + blind_17). SHA-256 46891b35...9388.
- **dcf_metals.py R-floor (L3189):** prints a warning when cysteine is below 0.4% of residues, because R divides by a tiny expected count there (*Leuconostoc*: R = 32 at 0.21% cysteine, L3181). Density and R values are unchanged; SHA-256 now 1850ab53…8ea3. Blind_16 (L3189) is graded with the frozen a640abc9… version, which gives the same numbers.
- **seen_names.txt (L3189):** organism-name list to check alongside `seen_accessions.txt`; *L. plantarum* NC_004567 (used in Note G set 5) added to the accession list.
- **dcf_secflag.py (L3161):** label-free selenocysteine candidate finder (upstream and downstream read-through through TGA). Development recall 45/69 (L3157); reliable only on AT-rich genomes (GC < 0.45). Blind test (L3165): recall 20/35 (57%) on AT-rich genomes (pass), but more than 100 candidates in 4 of 5 (fail); overall recall 34/52.
- **v2.31 (L3149): genome-size prior in genetic-code detection.** When the read-through test says table 11 and the ORF-length ratio says table 4, the ratio no longer overrides for genomes > 2.5 Mb (known table-4 bacteria are at most about 2.2 Mb). Fixes the blind miss on *Gluconobacter oxydans* (L3145). Blind test (L3153): 4 of 4 predictions passed on 6 new genomes; code called correctly in all 6 (blind code record 86 of 89).
- **dcf_metals.py (L3125):** label-free metal-use profile. CxxC (Fe-S) density separates methanogens from aerobes (L3117: 3.4x, p = 6e-5). The C2H2 zinc-finger counter is validated on 8 human proteins (8/8 within +-1 of literature counts; 267x over shuffled); C2H2 is rare in all 18 prokaryotes tested.
- **Blind set 8 (L3093), dcf_pylflag.py gene list:** in 4 new methylamine methanogens, all **21 of 21** pyrrolysine methyltransferases (annotated 'pseudo') were listed as TAG read-through candidates, with 9–20 candidates per genome. The genome-level excess would have flagged only 1 of 4. 3 of 3 predictions passed.
- **Blind set 7 (L3081), dcf_pylflag.py:** pyrrolysine methanogens were flagged (*M. mazei* 5.06, *M. burtonii* 3.72, *M. barkeri* 2.06); the bacterium *Desulfitobacterium hafniense* was missed (1.28); 4 of 4 non-users were not flagged (1.46–1.61). 3 of 4 predictions passed: the groups did not separate fully. Non-users sit at a baseline excess of about 1.5, not 1.
- **dcf_pylflag.py (L3073):** label-free stop read-through flag. In *M. acetivorans* it flags all 7 pyrrolysine methyltransferases (which RefSeq marks as pseudogenes), with 22 TAG joins in total and a TAG excess of 2.90. In 8 of 9 genomes without pyrrolysine the excess is below 2 (*S. pneumoniae* 2.04, from pseudogenes).
- **Fix (L3069), `dcf_grade.py` and `dcf_promoters.py`:** the GenBank reader dropped IUPAC ambiguity letters (R, Y, K, …), shifting every later coordinate in genomes that contain them (e.g. *Vibrio* NC_002505, *H. pylori* NC_000915). They are now kept as N. Grades (found / correct / exact start) were unaffected, because they use coordinates only. Promoter checks re-run on the four affected genomes kept their verdicts. The gene finder's own reader was always correct.
- **v2.30 (L3009/L3013):** learned start window widened from 20 to 30 nt, reaching archaeal promoter elements of leaderless genes (*Sulfolobus* 72.3 → 75.7%). Blind *S. epidermidis*: exact starts 91.2% (v2.29) → 92.0%, with no loss. Regression: mixed (−1.4 to +2.4 points in exact starts); codes, found and precision unchanged.
- **v2.29 (L3001):** learns each genome's start signal (upstream log-odds −20..−1 plus start-codon preferences) in two passes. Development exact starts: *Bacteroides* 52.4 → 70.2%, *E. coli* 79.4 → 85.4%, *Vibrio* 75.5 → 83.1%. 14-genome regression clean.
- **v2.28 (L2993):** the start search extends back to the previous in-frame stop. **Fixes a regression in v2.26–v2.27,** where starts were searched only downstream of the best-start trim (*E. coli* exact starts 81.4% in v2.24 → 63.0% → 79.4%). The 50%-overlap grader could not see this, so exact start is now reported by `dcf_grade.py`.
- **v2.27 (L2973):** best-start scoring for every genome, ORF minimum 240 nt. **Fixes a regression in v2.26:** code detection is restored to v2.25 (*Hodgkinia* had been miscalled as standard code).
- **v2.26 (L2969):** GC > 0.55 genomes are scored from the best start codon, minimum 180 nt. Held-out *Streptomyces* found 74.5 → 94.9%.
- **v2.25 (L2957):** tiny AT-rich genomes (< 300 kb, GC < 0.25) use the length ratio at a 1.45 cut for TGA = Trp.
- **v2.24 (L2921):** dispersed-repeat flag. **Fixes a strand bug** in the v2.22–v2.23 codon-phase strength line.
- **Labelling correction (L2973):** *M. genitalium* NC_000908 and *Deinococcus* NC_001263 had been used in development and were wrongly counted as unseen in blind set 2. Every new genome is now checked against `seen_accessions.txt`.
