# Changelog
- **Blind set 7 (L3081), dcf_pylflag.py:** pyrrolysine methanogens were flagged (*M. mazei* 5.06, *M. burtonii* 3.72, *M. barkeri* 2.06); the bacterium *Desulfitobacterium hafniense* was missed (1.28); 4 of 4 non-users were not flagged (1.46–1.61). 3 of 4 predictions passed: the groups did not separate fully. Non-users sit at a baseline excess of about 1.5, not 1.
- **dcf_pylflag.py (L3073):** label-free stop read-through flag. In *M. acetivorans* it flags all 7 pyrrolysine methyltransferases (which RefSeq marks as pseudogenes), with 22 TAG joins in total and a TAG excess of 2.90. In 8 of 9 genomes without pyrrolysine the excess is below 2 (*S. pneumoniae* 2.04, from pseudogenes).
- **Fix (L3069), `dcf_grade.py` and `dcf_promoters.py`:** the GenBank reader dropped IUPAC ambiguity letters (R, Y, K, …), shifting every later coordinate in genomes that contain them (e.g. *Vibrio* NC_002505, *H. pylori* NC_000915). They are now kept as N. Grades (found / correct / exact start) were unaffected, because they use coordinates only. Promoter checks re-run on the four affected genomes kept their verdicts. The gene finder's own reader was always correct.
- **v2.30 (L3009/L3013):** learned start window widened from 20 to 30 nt, reaching archaeal promoter elements of leaderless genes (*Sulfolobus* 72.3 → 75.7%). Blind *S. epidermidis*: exact starts 91.2% (v2.29) → 92.0%, with no loss. Regression: mixed (−1.4 to +2.4 points in exact starts); codes, found and precision unchanged.
- **v2.29 (L3001):** learns each genome's start signal (upstream log-odds −20..−1 plus start-codon preferences) in two passes. Development exact starts: *Bacteroides* 52.4 → 70.2%, *E. coli* 79.4 → 85.4%, *Vibrio* 75.5 → 83.1%. 14-genome regression clean.
- **v2.28 (L2993):** the start search extends back to the previous in-frame stop. **Fixes a regression in v2.26–v2.27,** where starts were searched only downstream of the best-start trim (*E. coli* exact starts 81.4% in v2.24 → 63.0% → 79.4%). The 50%-overlap grader could not see this, so exact start is now reported by `dcf_grade.py`.
- **v2.27 (L2973):** best-start scoring for every genome, ORF minimum 240 nt. **Fixes a regression in v2.26:** code detection is restored to v2.25 (*Hodgkinia* had been miscalled as standard code).
- **v2.26 (L2969):** GC > 0.55 genomes are scored from the best start codon, minimum 180 nt. Held-out *Streptomyces* found 74.5 → 94.9%.
- **v2.25 (L2957):** tiny AT-rich genomes (< 300 kb, GC < 0.25) use the length ratio at a 1.45 cut for TGA = Trp.
- **v2.24 (L2921):** dispersed-repeat flag. **Fixes a strand bug** in the v2.22–v2.23 codon-phase strength line.
- **Labelling correction (L2973):** *M. genitalium* NC_000908 and *Deinococcus* NC_001263 had been used in development and were wrongly counted as unseen in blind set 2. Every new genome is now checked against `seen_accessions.txt`.
